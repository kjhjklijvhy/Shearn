# Contribution Guidelines

## Code Style
- Use TypeScript
- Follow Prettier formatting
- ESLint rules mandatory
- Meaningful commit messages

## Branch Naming
- `feature/description`
- `bugfix/description`
- `hotfix/description`

## Pull Request
- Descriptive title
- Clear description
- Link related issues
- All tests must pass

## Commit Messages
```
type(scope): subject

body

footer
```

Types: feat, fix, docs, style, refactor, test, chore

## Testing
All code changes require tests.
